**EMBERFALL** — Hold the last light. A neon wave-survival arena shooter: fly the
last light-ship through 10 waves of the Hollow Tide, break the Ember Colossus on
waves 5 and 10, and pick 1 of 3 upgrades after every cleared wave. WASD to move,
mouse to aim, hold click to fire, SHIFT to dash, E for a nova bomb. Combos, gems,
pickups, synth sound, and a victory screen when all 10 waves fall. Original art,
code and sounds; no library, no network — just static files.

## Run it

```sh
node serve.ts
# open http://localhost:8080 in desktop Chrome
```

Or hand it in exactly as the grader does:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Screenshots in `screenshots/` are real renders of this game's own code
(`?shot=play|start|boss|victory&seed=7`).
